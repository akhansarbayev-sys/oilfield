# Куст: бурение и ГРП

Интерактивная схема кустовой площадки: бурение и гидроразрыв пласта (ГРП).

Сайт — одна самодостаточная страница `index.html` без внешних зависимостей.

## Просмотр

- Онлайн: через GitHub Pages (Settings → Pages → Branch: `main`, папка `/root`).
- Локально: открыть `index.html` в браузере.
